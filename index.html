Settings

Choose a stimulus set to enable its response checks. Relational adds direction or higher/lower responses. For non-position dimensions, a non-zero executive offset can replace Same and (when Relational is on) Lower/Higher with offset-relative checks, or you can keep both sets of checks. Position has no executive offset. Settings are locked during a running session.

Stimulus dimensions & rules

Every selected set enables its identity check. For non-position dimensions, a non-zero executive offset can replace Same and, with Relational enabled, Lower/Higher; turn off “Replace normal response checks” to keep both. Executive offsets wrap around the ordered set. Position does not use executive offsets.

CCT mode

Use ignored other channel

CCT response rule: the current digit plus the immediately previous digit must sum to the same value as the digit pair ending N trials earlier. The visual digit stream can be represented by mapped faces whenever it is the target or ignored channel. The ignored channel always receives a different digit. CCT needs one extra warm-up trial because it compares digit pairs.

Emotional faces & uploads

Nine built-in photographic faces are included. When CCT uses a visual digit stream (target or distractor), selecting Emotional stimuli → Face images represents those digits with faces. Uploaded images persist locally in this browser.
